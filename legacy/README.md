# legacy归档

本文件夹存放旧版（Python + tkinter 时代）的完整产物，仅作历史留存与回退使用。

| 文件 | 说明 |
| --- | --- |
| RandomNameCall-Python-1.1.3.1-source.zip | 旧版全部源码 + 资源（main.py 全套、xkkRandomRollCall 包、wav/ico、spec 打包配置、LICENSE、发布指引、封装命令） |
| RandomNameCall-Python-1.1.3.1-installer.exe | 旧版标准安装包（Inno Setup，含卸载程序） |

旧版技术栈：Python 3.8+ / tkinter / pygame / PyInstaller。
旧版更新源指向 GitHub Releases API（仓库 Rb9-1376/RandomNameCall 的 v1.1.3.1 release）。

当前主力版本：根目录的 Electron 重构版（0.2.0.0），维护方法见《MAINTENANCE.md》。
